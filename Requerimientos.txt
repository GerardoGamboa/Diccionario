
En todas las páginas en la parte inferior, se debe tener un pie de página muy pequeño con la leyenda "Basis datorum | 2026".

Al momento de agregar una nueva tabla en la aplicación no solo se debe de solicitar la base de datos a la que pertenece, sino se debe solicitar: el servidor y posteriormente la base de datos, considerando que las bases de datos que se muestren dependerán del servidor que se seleccionó anteriormente.

Al momento de agregar un nuevo procedimiento en la aplicación no solo se debe de solicitar la base de datos a la que pertenece, sino se debe solicitar: el servidor y posteriormente la base de datos, considerando que las bases de datos que se muestren dependerán del servidor que se seleccionó anteriormente.

Al momento de agregar una nueva función en la aplicación no solo se debe de solicitar la base de datos a la que pertenece, sino se debe solicitar: el servidor y posteriormente la base de datos, considerando que las bases de datos que se muestren dependerán del servidor que se seleccionó anteriormente.

Al momento de agregar un nuevo disparador en la aplicación no solo se debe de solicitar la tabla a la que pertenece, sino se debe solicitar: el servidor, la base de datos y posteriormente la tabla, considerando que las bases de datos que se muestren dependerán del servidor y que las tablas que se muestren dependerán de la base de datos seleccionada.

En los eventos de los disparadores, se deben tener predefinidos los tipos: "INSERTAR", "INSERTAR y ACTUALIZAR", "ACTUALIZAR" y "ELIMINAR"

Se debe contar con varios reportes:
1. Un reporte que muestre por cada base de datos, las tablas involucradas y por cada tabla las columnas con sus características.
2. Un reporte que muestre por cada base de datos los procedimientos, disparadores y funciones que contiene.
En ambos reportes debe poder filtrarse por base de datos.
